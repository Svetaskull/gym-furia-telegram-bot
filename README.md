# 💅 Gym Furia Telegram Bot

Фурия — автономная комментаторша Telegram-канала с собственным характером, памятью, зрением и слухом.

Она читает публикации канала через связанную группу обсуждений, иногда оставляет комментарии и может продолжать разговор с пользователями в ветке ответов.

## Характер

Фурия — дерзкая, саркастичная и немного стервозная женщина, которая обожает спортзал, тяжёлые тренировки и привлекательных взрослых мужчин.

При этом она не является фитнес-тренером, психологом или мотивационным коучем.

Спортзал влияет на её взгляд на жизнь, но не является единственной темой её личности.

Характер персонажа хранится отдельно в:

`furia_prompt.txt`

## Возможности

- автоматические комментарии к публикациям Telegram-канала;
- случайная вероятность комментария;
- случайная задержка перед публикацией;
- продолжение разговора при ответе пользователю;
- сохранение истории разговоров;
- анализ фотографий;
- анализ видео по нескольким кадрам;
- извлечение аудиодорожки из видео;
- распознавание человеческой речи;
- объединение текста, изображения, видео и речи в одном контексте;
- локальный кэш обработанных видео;
- повторное использование кэша при продолжении разговора.

## Память

Разговоры сохраняются локально в:

`furia_memory.json`

Файл создаётся автоматически и не добавляется в Git.

## Видеокэш

Обработанные кадры и расшифровки видео сохраняются локально в:

`video_cache/`

Каталог не добавляется в Git.

## Переменные окружения

Для работы необходимы:

`OPENAI_API_KEY`

`FURIA_TELEGRAM_BOT_TOKEN`

Токены и API-ключи не должны храниться в исходном коде или публиковаться в репозитории.
